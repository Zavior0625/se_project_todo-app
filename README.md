# Simple Todo App

TaskFlow is a simple and responsive web application that allows users to create, manage, and organize daily tasks. The app provides an easy way to keep track of responsibilities by adding, completing, and removing todo items through an interactive user interface.

## Functionality

The application allows users to add new tasks using a form input and display them dynamically in a task list. Each task can be marked as completed to help users track progress throughout the day. Users can also delete tasks they no longer need, keeping the list organized and up to date. The interface updates in real time without refreshing the page, creating a smooth user experience. Form validation is included to prevent empty tasks from being submitted. The layout is designed to be clean, accessible, and responsive so it works well on both desktop and mobile devices.

## Technology

This project was built using HTML, CSS, and JavaScript. HTML provides the structure of the application, CSS is used for styling and responsive layout design, and JavaScript handles the interactive functionality such as creating, updating, completing, and deleting tasks dynamically. The project uses DOM manipulation and event listeners to update the interface in real time based on user actions. Modular JavaScript techniques were used to organize the code and improve readability and maintainability. The application is deployed using GitHub Pages for easy online access and sharing.
